# Тренировка git — ветка `test`

Здесь можно ломать что угодно. Цель — к старту CTF уверенно делать `pull` → `commit` → `push` из консоли.
Шпаргалка по командам — `GIT.md` в корне.

## Задание 1. Свой первый push

```powershell
git switch test
git pull
```

Создай файл `test/<твой_ник>.md` и напиши в нём что угодно (например, какое направление берёшь на CTF). Потом:

```powershell
git add .
git commit -m "test: привет от <ник>"
git push
```

Проверь на GitHub: переключи ветку на `test` — твой файл должен появиться.

## Задание 2. Чужие изменения

Подожди, пока запушит кто-то ещё, затем `git pull` — его файл должен появиться у тебя.

## Задание 3. Конфликт (самое важное)

Все одновременно открывают `test/team.md` и **меняют одну и ту же строку** — строку `Капитан:`.
Каждый коммитит и пушит. Первый пройдёт, у остальных `push` откажет → `git pull` → `CONFLICT`.
Разрули конфликт (см. «Если что-то пошло не так» в `GIT.md`) и запушь.

## Задание 4. Своя ветка

```powershell
git switch -c test-<ник>
# поменяй что-нибудь
git add .
git commit -m "test: моя ветка"
git push -u origin test-<ник>
```

На GitHub в списке веток появится твоя. Так же во время CTF будут работать ветки `web`, `crypto` и т.д.
