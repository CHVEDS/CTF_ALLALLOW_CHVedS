# Git для команды — шпаргалка

## Один раз: настроить git

```powershell
git config --global user.name "твой_ник"
git config --global user.email "почта_от_github@example.com"
```

## Один раз: скачать репозиторий

```powershell
cd D:\
git clone https://github.com/CHVEDS/CTF_ALLALLOW_CHVedS.git
cd CTF_ALLALLOW_CHVedS
```

При первом `push` Windows откроет окно входа в GitHub — войди своим аккаунтом.

## Каждый раз: основной цикл

```powershell
git switch web            # перейти в ветку своего направления
git pull                  # забрать чужие изменения — ВСЕГДА перед работой
# ... работаешь, создаёшь/меняешь файлы ...
git add .                 # добавить всё изменённое
git commit -m "web: task-name — решено, флаг в notes.md"
git push                  # отправить на GitHub
```

Если `push` ругается `rejected ... fetch first` — кто-то запушил раньше тебя. Сделай `git pull`, потом снова `git push`.


## Полезные команды

| Команда | Что делает |
|---|---|
| `git status` | что изменено и в какой ты ветке |
| `git branch -a` | список всех веток (и на GitHub тоже) |
| `git switch <ветка>` | перейти в ветку |
| `git switch -c <ветка>` | создать новую ветку и перейти в неё |
| `git push -u origin <ветка>` | первый push новой ветки на GitHub |
| `git log --oneline -10` | последние 10 коммитов |
| `git restore <файл>` | отменить свои несохранённые правки в файле |

## Если что-то пошло не так

- **`CONFLICT` после `git pull`** — ты и кто-то другой поменяли одни и те же строки. Открой файл, найди блок между `<<<<<<<` и `>>>>>>>`, оставь нужный вариант, удали эти маркеры, затем `git add .`, `git commit`, `git push`.
- **Открылся непонятный редактор после `git pull`** — это сообщение merge-коммита. Блокнот/VS Code — просто закрой. Чёрный экран (Vim) — набери `:wq` и Enter.
- **`index.lock: File exists`** — `del .git\index.lock` и повтори команду.
- **Закоммитил не в ту ветку** — не паникуй и не делай `push -f`, напиши в чат команды.
