## Установка (Windows 10/11)

### Шаг 1. Скачай репозиторий

**Вариант А — архивом (проще).** На странице репозитория нажми зелёную кнопку **Code → Download ZIP**. Распакуй архив, например в `D:\CTF`. Внутри будет папка `CTF_ALLALLOW_CHVedS-main` с файлами `install.cmd` и `install.ps1`.

**Вариант Б — через git** (если git уже стоит; так проще получать обновления командой `git pull`):

```powershell
cd D:\
git clone https://github.com/CHVEDS/CTF_ALLALLOW_CHVedS.git
```

### Шаг 2. Запусти установщик

**Самый простой способ:** открой папку с файлами в проводнике и дважды кликни **`install.cmd`**. Если Windows покажет окно «Система Windows защитила ваш компьютер» — нажми **Подробнее → Выполнить в любом случае**.

**Через PowerShell:**

1. Нажми **Пуск**, набери `PowerShell`, кликни правой кнопкой → **Запуск от имени администратора**.
2. Перейди в папку, куда распаковал репозиторий. Путь бери свой: проще всего открыть папку в проводнике, кликнуть по адресной строке и скопировать путь.

   ```powershell
   cd "D:\CTF\CTF_ALLALLOW_CHVedS-main"
   ```

   Кавычки нужны, если в пути есть пробелы. Проверить, что ты в нужной папке: команда `dir` должна показать `install.cmd` и `install.ps1`.
3. Запусти:

   ```powershell
   .\install.cmd
   ```

> Подсказка: в проводнике можно зажать **Shift**, кликнуть правой кнопкой по пустому месту в папке и выбрать **«Открыть окно PowerShell здесь»** (или **«Открыть в терминале»**) — тогда шаг 2 делать не нужно.

### Шаг 3. Выбери наборы

Откроется отдельное окно на весь экран. В меню выбери наборы цифрами через запятую, например `1,2,3`, или `A` — всё сразу. Описание наборов — ниже. После установки скрипт спросит «Установить что-нибудь ещё?» и вернёт в меню; уже поставленные наборы помечены `✓`. Выход — `Q`.

Если что-то не установилось — путь к логу будет в конце, пришли его Heres.

### Если появилась ошибка «файл не имеет цифровой подписи»

Так PowerShell реагирует на скрипты, скачанные из интернета. Запускай через `install.cmd` — он обходит эту проверку. Либо выполни в окне PowerShell (действует только на это окно):

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

### Дополнительные параметры

| Параметр | Что делает |
|---|---|
| `-Sets web,crypto` | сразу ставит указанные наборы, без меню |
| `-All` | все наборы сразу |
| `-NoIntro` | без заставки |
| `-NoFullscreen` | не разворачивать окно на весь экран |
| `-NoSound` | без звука печати |
| `-NoGlitch` | без «лагов» и помех в тексте |

Пример: `.\install.cmd -Sets web,crypto -NoIntro`

## Как работает установщик

- **Полный экран.** Скрипт открывает себя в отдельном окне консоли, подбирает размер шрифта под экран (~125 символов в ширину) и разворачивает окно. Нажатия клавиш не эмулируются. Отключить — `-NoFullscreen`.

- **Уже установленное не трогается.** Проверка идёт через `winget list`, наличие команды в PATH (`git`, `py`, `node`…) или известный путь установки, поэтому программы, поставленные вручную, тоже распознаются.
- **Обновления — только с твоего согласия.** Если есть версия свежее, скрипт показывает `текущая -> новая` и спрашивает по каждой программе (`y` — да, `N` — нет, `a` — да для всех оставшихся).
- **Тяжёлые программы** (Docker Desktop) спрашиваются отдельно.
- **Ручные пункты** (Ghidra — его нет в winget) — скрипт предлагает открыть страницу загрузки.
- Одинаковые пункты из разных наборов ставятся один раз.
- Лог каждого запуска — в `logs/` (папка в git не попадает).

Нужен **winget** (есть в Windows 10/11 по умолчанию, иначе — «App Installer» из Microsoft Store). Python-пакеты ставятся через `py -m pip`. Если Python ещё нет — выбери набор BASE, скрипт поставит его первым и затем доставит pip-пакеты.

Ставь первым, нужен всем.

|---|---|---|

| Python 3 | winget | скрипты решений, основа для pip-пакетов |

### 7. OSINT — поиск информации
В основном это браузерные сервисы, установщик ставит только ExifTool и Firefox и выводит ссылки:

- [Wayback Machine](https://web.archive.org) — старые версии сайтов

- [CyberChef](https://gchq.github.io/CyberChef) — кодировки и преобразования (пригодится везде)

## Добавить свою программу
Найди ID: `winget search <название>`, затем добавь строку в нужный набор в `$Catalog` в `install.ps1`:

```powershell
@{ Name='Название'; Kind='winget'; Id='Publisher.Package'; Cmd='команда' }
@{ Name='пакет';    Kind='pip';    Id='имя-на-pypi' }
```
и строку в таблицу этого README.
