# h3r3s — помощник на CTF

Консольная программа, которая быстро расшифровывает строки и ищет флаг в файлах.

## Как запустить

1. Нужен Python — поставь набор **BASE** через `install.cmd` в корне репозитория.
2. Дважды кликни **`helper\h3r3s.cmd`**.

Откроется окно на весь экран. Выбираешь модуль цифрой и жмёшь Enter.

## Модули

| № | Модуль | Что делает | Что ему дать |
|---|---|---|---|
| 1 | **Декодер** | Снимает слои кодировки: base64, hex, url, base85, rot13, XOR и т.п. | Вставь строку (Ctrl+V) или перетащи файл |
| 2 | **Охотник** | Ищет `SOLARCTF{...}` во всех файлах, в т.ч. в закодированном виде и внутри архивов | Перетащи файл или папку |
| 3 | **Что за файл** | Настоящий тип файла, энтропия, спрятанные внутри файлы | Перетащи файл |
| 4 | **Шаблоны** | Готовые заготовки Python-скриптов (PPC, z3, XOR, HTTP) | Номер шаблона |

## Главное

- **Пути печатать не нужно** — перетащи файл мышкой в окно и нажми Enter.
- **Найденный флаг сам копируется в буфер обмена** — сразу Ctrl+V в форму сдачи.
- **Из модуля выходишь сам** — пустой Enter. До этого можно кидать файлы или строки сколько угодно.
- **Если не нашёл** — это не значит, что флага нет. Программа помогает с типовыми случаями, сложное решаем руками и в чате команды.

## Параметры

Дописать при запуске из консоли, например `helper\h3r3s.cmd -NoIntro`:

| Параметр | Что делает |
|---|---|
| `-NoIntro` | без заставки |
| `-NoSound` | без звука |
| `-NoGlitch` | без помех на экране |
| `-NoFullscreen` | не разворачивать окно |
