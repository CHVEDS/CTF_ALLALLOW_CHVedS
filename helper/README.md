# h3r3s — помощник команды на CTF

Консольный инструмент под SolarCTF: быстро раскодировать, найти флаг в файлах, опознать файл, достать готовый шаблон скрипта. Сделан под почерк заданий Solar 4RAYS (форензика + реверс), где флаг обычно спрятан цепочкой кодировок и XOR.

## Запуск

Дважды кликни **`h3r3s.cmd`**. Откроется отдельное окно на весь экран — как у установщика. Нужен Python — он есть в наборе **BASE** установщика.

Параметры (можно дописать к `h3r3s.cmd`): `-NoIntro` без заставки, `-NoFullscreen` не разворачивать окно, `-NoSound` без звука, `-NoGlitch` без помех.

Пути к файлам и папкам можно не печатать — просто перетащи файл мышкой в окно и нажми Enter. Найденный флаг сразу копируется в буфер обмена.

Внутри модуля можно работать сколько угодно: вставлять строку за строкой или файл за файлом. Выйти в меню — **пустой Enter**. В начале каждого модуля есть подсказка «как пользоваться».

Как устроено: `h3r3s.ps1` — интерфейс (тот же движок оформления, что у установщика), `engine.py` — «мозг»: расшифровка, поиск, анализ. Шаблоны сохраняются в `helper/scripts/`.

## Модули

### 1. Магический декодер
Вставляешь непонятную строку **или перетаскиваешь файл** (тогда берётся его содержимое; если флаг сидит внутри текста, например в XML-теге, кусок найдётся сам) — разворачивает слои сам: base64 / base64url / base32 / base85, hex, URL, UTF-16 (убирает нулевые байты), ROT13, reverse, десятичные коды, zlib/gzip. На каждом слое пробует **XOR**: одним байтом перебором и многобайтовым ключом, вычисленным по известному началу флага (`SOLARCTF{`). Выдаёт самый короткий рецепт, например `url > base85 > xor(key=K3Y)`, и подсвечивает флаг.

Решает ровно те цепочки, что были в прошлогоднем FlagHunt: `base64 → убрать нули`, `hex → XOR`, `base64 → hex → XOR`, `url → base85 → XOR`.

### 2. Охотник за флагом
Даёшь файл или папку с артефактами — прочёсывает всё:
- строки ASCII **и UTF-16** (так флаг хранят Windows-программы и дампы реестра);
- закодированные блобы внутри файлов — каждый прогоняет через декодер;
- заходит внутрь архивов zip / tar / gzip, в том числе вложенных друг в друга.

Показывает только то, что раскрылось во флаг. На форензике часто находит за минуту.

### 3. Что это за файл
Тип по сигнатуре (а не по расширению), предупреждает о подмене расширения, энтропия (высокая → зашифровано/упаковано), вложенные файлы как binwalk (zip/png/pdf внутри другого файла), строки и флаг прямо в них.

### 4. Шаблоны скриптов
Сохраняет рядом готовую заготовку:
- `ppc_spam.py` — массовая отправка запросов с куки (как Homyak Tap);
- `solve_z3.py` — восстановление флага через SMT-солвер (как Rusty love);
- `xor_crack.py` — XOR с ключом по известному началу флага;
- `http_probe.py` — прощупать эндпоинты сайта.

## Формат флага
По умолчанию ищет `SOLARCTF{...}` (и заодно `4rays{`, `flag{`, `CTF{`). Поменять — в начале `h3r3s.py`, список `FLAG_PREFIXES`.

## Не замена инструментам
Это быстрый первый заход. Серьёзную форензику всё равно делаем в Wireshark, RegistryExplorer, CyberChef, IDA/Ghidra — они в наборах установщика.
